Что значит каждый пункт

●Редкость кольца
Задаёт общий «бюджет» уровней эффектов (Σ = 2/3/4/5/6). Чем выше редкость — тем больше бюджет, но это не значит «больше эффектов»: бюджет может уйти как в новые эффекты, так и в прокачку уже существующих.
●Тип кольца
7 из 8 типов имеют встроенный эффект — он гарантирован на 100% и всегда занимает первый слот в цикле распределения (поэтому его чаще прокачивают выше). «Полое» — единственное без встроенного эффекта: все его слоты берутся из общего пула 85.
●Что считаем: «Встроенный эффект»
Считает шанс, что именно встроенный эффект кольца (позиция №1) окажется нужного уровня. Присутствие уже 100% — вся вероятность зависит только от уровня.
●Что считаем: «Эффект из пула (85)»
Считает шанс для одного конкретного эффекта из общего пула (31 обычный + 54 варианта мастерства = 85). Тут важны два фактора: попадёт ли он вообще на кольцо, и если попадёт — какой у него будет уровень.
●Подтип встроенного эффекта (радужное)
Только у радужного кольца встроенный эффект имеет 3 равновероятных подтипа. «Любой из 3» — не важно какой (100%). «Конкретный подтип» — считаем шанс именно на один определённый вариант (1/3).
●Сравнение уровня
«Не ниже (≥)» — суммирует шансы на нужный уровень и выше (обычно это и есть практический вопрос «хватит ли силы эффекта»). «Ровно (=)» — только точное совпадение уровня, без учёта более высоких.
●Нужный уровень
Целевой уровень эффекта (1–5), с которым сравнивается фактический результат по правилу выше.

Формулы для каждого случая

1Встроенный эффект, не радужное
P = P_уровень(L | позиция №1)
Присутствие = 100%, поэтому итог — это просто распределение уровня встроенного эффекта из таблицы «Разбор данных».
2Встроенный эффект, радужное — любой из 3 подтипов
P = P_уровень(L | позиция №1)
Так же, как встроенный эффект обычного кольца — подтип не фильтруется.
3Встроенный эффект, радужное — конкретный подтип
P = (1/3) × P_уровень(L | позиция №1)
Домножаем на 1/3, так как нужен ровно один из трёх равновероятных подтипов.
4Эффект из пула — кольцо со встроенным эффектом
P = (E[k] − 1) / 85 × P_уровень(L | пул)
E[k] — среднее число слотов эффектов на кольце этой редкости; «−1» убирает встроенный слот, ведь он не из пула. Делим на 85 = 31 обычных + 54 варианта мастерства.
5Эффект из пула — полое кольцо
P = E[k] / 85 × P_уровень(L | любая позиция)
Без встроенного эффекта все E[k] слотов — из пула, поэтому «−1» здесь не нужно.
