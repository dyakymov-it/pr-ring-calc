# Калькулятор шанса для колец — Pocket Rogues

Неофициальный фан-инструмент от комьюнити [Pocket Rogues](https://store.steampowered.com/app/946610/Pocket_Rogues/) — Action-RPG с рогалик-элементами. Все права на игру, её механики и арт принадлежат разработчику EtherGaming.

Официальный Telegram-канал игры: https://t.me/pocket_rogues_news

## Что делает калькулятор

Считает **точный** (не через симуляцию, а через рекурсивный разбор всех вероятностных путей) шанс того, что на кольце определённой редкости и типа появится нужный эффект нужного уровня.

В основе — механика распределения уровней эффектов на кольце: у каждой редкости есть общий «бюджет» уровней (2/3/4/5/6), который распределяется по циклу — с шансом 20% повысить уровень уже существующего эффекта, иначе добавляется новый эффект из общего пула.

## Параметры

- **Редкость кольца** — задаёт бюджет уровней (Обычное=2, Особое=3, Древнее=4, Эпическое=5, Легендарное=6). Бюджет не равно количеству эффектов: он может уйти как в новые эффекты, так и в прокачку уже существующих.
- **Тип кольца** — 7 из 8 типов имеют встроенный эффект (гарантирован на 100%, всегда занимает первый слот и потому чаще прокачивается выше). «Полое» — единственное без встроенного эффекта, все его слоты берутся из общего пула.
- **Что считаем** — «Встроенный эффект» (позиция №1, присутствие уже 100%) или «Эффект из пула» (один конкретный эффект из 85: 31 обычный + 54 варианта мастерства).
- **Подтип встроенного эффекта (только у радужного)** — у радужного кольца встроенный эффект имеет 3 равновероятных подтипа. Можно считать «любой из 3» либо конкретный один (1/3).
- **Сравнение уровня** — «не ниже» (≥, суммирует шансы на нужный уровень и выше) или «ровно» (=, только точное совпадение).
- **Нужный уровень** — целевой уровень эффекта (1–5).

## Формулы

**1. Встроенный эффект, не радужное**
```
P = P_уровень(L | позиция №1)
```

**2. Встроенный эффект, радужное — любой из 3 подтипов**
```
P = P_уровень(L | позиция №1)
```

**3. Встроенный эффект, радужное — конкретный подтип**
```
P = (1/3) × P_уровень(L | позиция №1)
```

**4. Эффект из пула — кольцо со встроенным эффектом**
```
P = (E[k] − 1) / 85 × P_уровень(L | пул)
```
где E[k] — среднее число эффектов на кольце этой редкости, «−1» убирает встроенный слот (он не из пула).

**5. Эффект из пула — полое кольцо**
```
P = E[k] / 85 × P_уровень(L | любая позиция)
```
Без встроенного эффекта все слоты — из пула, поэтому «−1» не нужно.
